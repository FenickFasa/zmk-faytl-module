# ZMK Module Template

This repository contains the shield files for the FAYTL to allow users to build firmware. This can be done by adding the module to the west.yml found in your zmk-config's config directory. There is a full guide available for this here: [ZMK Module Creation](https://zmk.dev/docs/development/module-creation)

## Usage

Edit your west.yml file found in your zmk-config's config directory to add the FAYTL module.
